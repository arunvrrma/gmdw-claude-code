# Archived process reports

Point-in-time reports from the MVP (`v0.1.0`) release and its first live-validation
runs, kept for provenance. They are historical records, not living documentation —
current guidance is in the top-level `README.md`, `docs/GETTING_STARTED.md`,
`docs/KNOWN_LIMITATIONS.md`, and `docs/RELEASE_READINESS.md`.

- `HANDOFF.md` — MVP-era implementation handoff to the engineer running the first
  live validation.
- `LIVE_VALIDATION_READINESS.md` — the readiness gate for the first live-validation
  run on the (since-merged) `live-validation` branch.
- `LIVE_VALIDATION_EXECUTION.md` — the operator-followable process used for that
  live-validation run.
- `RELEASE_CHECKLIST.md` — the gate checklist for cutting the frozen
  `v0.1.0-mvp` baseline.

One curated example run (`wf_20260714_001`) is committed for reference; new runs
stay local by default (see `.gitignore`). Other run IDs cited in ADRs and historical
docs were local runs and are intentionally not in the tree.
